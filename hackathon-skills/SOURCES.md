## Reproducing this install

```bash
git clone --depth 1 https://github.com/Leonxlnx/taste-skill
git clone --depth 1 https://github.com/mattpocock/skills

# Spec Kit: generate with the CLI, do not copy from a clone
specify init --here --force --integration agy --ignore-agent-tools --non-interactive

# Then copy into <project>/.agents/skills/:
cp -r taste-skill/skills/taste-skill   <project>/.agents/skills/design-taste-frontend
cp -r skills/skills/engineering/{tdd,code-review,diagnosing-bugs} <project>/.agents/skills/
cp -r skills/skills/productivity/{grill-me,grilling}              <project>/.agents/skills/
```
